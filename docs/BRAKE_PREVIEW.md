# v1.2-preview 刹车反馈

本预览版替换 L2 刹车算法。R2、路面/路肩音圈、握把反馈的算法保持原样。目标是在无 ABS 赛车轮速开始异常下降时更早给出可感知的阻力，同时保留 GT3 的 ABS 介入提示。

## 使用

“自适应扳机”中的刹车模式可选自动、有 ABS、无 ABS / ABS 已关闭。自动模式区分 mABSActive（正在介入）、mABSMax（可用设置）、mABS（当前档位），不会把“此刻没有介入”等同于“没有 ABS”。游戏设置字段未正确更新时，请按实际车辆/ABS 设置选择模式。自动识别状态未知时界面提示选择模式，不猜测车辆类别。

- 有 ABS：首次介入的物理帧直接增加 L2 阻力，记录本次制动的输入位置；同一次制动中较低的再次介入位置更新阻力墙。松开至墙下方或结束制动即清除，不沿用到下一个弯角。
- 无 ABS：分别计算四轮风险，前后各取最大值，再取较大者驱动 L2；单个后轮的风险不会被四轮平均稀释。接近阈值时先增加阻力，明显抱死时增加浅幅 18 Hz 阻力变化。
- 两种模式均使用 0x21 分区阻力。风险反馈叠加在基础曲线上，避免原 0x26 低幅脉冲替换基础刹车阻力。
- 调节“ABS 阻力墙”或“临界制动预警”的强度，再保存配置。阻力墙位置按游戏的未过滤刹车输入估算，要求游戏中的刹车轴接近线性；本程序没有读取手柄的实际 L2 行程。非线性曲线、死区会影响阻力墙位置。

这是一种触觉提示，不限制刹车输入，不执行自动防抱死，也不能保证最佳制动力或避免失控。

## 信号与时间

已有的逐轮轮速、轮胎局部纵向地速、接地载荷/压缩量继续使用。新增读取 wheel+32 的 mBrakePressure（当前接口的 0–1 比例，不能称为 kPa）和 wheel+112 的 mGripFract（接触面滑动比例估计，不能称为剩余抓地力）。字段布局来源为 pyLMUSharedMemory 的 LMUWheel，与仓库原有 260 字节车轮结构一致。

对已有可信有效半径的轮胎，制动滑移为 max(0, 1-|omega|*R/|v_ground|)。还计算每轮 |omega|/|v_ground| 的相对下降率，使用物理帧 mElapsedTime 的间隔，10 ms 导数平滑及有界 40 ms 前视；前视最多增加 0.12 滑移量。半径未就绪时，连续接地帧中相对滚动速度的累计下降提供瞬态证据，并保留持续减速后的轮速损失；它不能识别程序开始采样前已存在的恒定滑移，界面会标注“半径尚未就绪”。不使用未经实机核实的 patch velocity 符号去替代滑移。

预览默认预警区间为 0.06–0.16，明显抱死增强区间为 0.16–0.25；8 ms attack、40 ms release。这些是工程试验参数，并非所有轮胎共同的最佳滑移率。增大的逐轮刹车压力和接触面滑动比例只增强已存在的纵向风险，不能单独触发警报；侧滑角也不会单独触发 L2 抱死提示。回收制动可能没有液压压力，因此压力不作为唯一开关。

低于 5 m/s、松刹车、倒挡不输出风险提示；离地轮不计算风险，也不跨越离地/落地或运动方向反转计算导数。重复帧不积分；断流、暂停、换车和模式切换清除状态。输出仍按 250 Hz 调度；这是目标写入频率，实际游戏物理帧与 USB/机械响应延迟须实测。

## 验证与限制

新增测试覆盖：真实布局快照的字段注入、ABS 自动识别与手动选择、低于旧 30% 阈值的提示、相同滑移下的趋势提前量、后轮单独风险、半径未知时轮速崩塌/持续抱死/恢复、转弯轮速差、侧滑与离地抑制、松刹车与低速释放、ABS 首帧与再介入、基础阻力保持、强度单调性、重复帧、主机时钟抖动、断流及参数校验。Windows Actions 另外执行现有回归测试及十组合成回放。

自动测试验证软件行为，不验证真实轮胎摩擦峰值、用户感知提前量或 DualSense 电机响应。仍需用 GT3 和无 ABS Hypercar 的直线渐进制动、拖刹、压路肩及后轮先锁场景检验。记录驾驶数据时包含新增车轮字段，诊断区显示当前模式、前后风险、滑移/变化率和 ABS 阻力墙位置。
