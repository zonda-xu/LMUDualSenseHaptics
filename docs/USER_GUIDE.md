# 使用指南

## 首次连接

使用能传输数据的 USB 线连接 DualSense，在“路面与震动”中选择手柄音频设备。点击“Windows 声音设置”，确认手柄的**播放设备**已启用、未静音，并配置为四声道（Quadraphonic），建议采样率为 48 kHz。游戏声音继续使用原来的耳机或音箱。

离开 LMU 驾驶状态，在“连接与工具”中检查左、右握把震动；每次持续 1 秒。左右方向相反时，开启“交换左右震动”。也可分别检查 L2/R2 阻力及脉冲。检查“普通震动”按钮前，应关闭 USB 音圈模式。重新开启音圈模式后再进入驾驶。

## 各页设置

| 设置 | 用途 |
| --- | --- |
| TC 介入阻力 | 牵引力控制介入时增加 R2 阻力。默认开启“仅 TC 介入时增加阻力”，正常加速保持自由行程。 |
| R2 其他效果 | 关闭 TC 专用选项后，启用基础阻力、空转和转速上限提示；升挡也可作用于 R2。 |
| L2 基础阻力 / ABS / 抱死 | 分别调节渐进刹车阻力、ABS 介入和车轮抱死提示。 |
| 路面 / 路肩 | 调节颠簸纹理和压过路肩的震动。先调整这两项。 |
| 根据连续颠簸补充路肩识别 | 缺少游戏路肩标记时，使用单侧连续颠簸推断。普通粗糙路面也可能触发，可关闭。 |
| 音圈总强度 | 调节所有音圈效果的整体强度；Windows 设备或应用静音仍会阻止输出。 |
| 路面灵敏度 | 调节路面响应，100% 为初始值；不影响扳机或引擎。 |
| 左右分离 | 越高，左右路面和路肩的交叉传递越少。 |
| 震动频率 | 调节细密或低沉的触感。路肩节奏还会随车速变化。 |
| 车辆与事件 | 增加打滑、碰撞、升挡及引擎提示。引擎震动随转速变化，路面与路肩优先。 |

每项反馈右侧开关控制启用，滑块控制强度。修改立即生效；点击“保存配置”后，下次启动继续使用。录制驾驶数据时，反馈设置和外观暂时锁定，停止记录后可调整。

## 状态读数

- “驾驶中”表示正在读取驾驶数据并处理反馈。
- “音圈已启动”表示手柄音频输出已连接。顶部握把百分比显示软件合成的输出电平，实际触感请通过握住手柄确认。
- L2/R2 的 `1–8` 表示输出等级，`释放` / `自由行程` 表示没有施加扳机效果。
- 暂停、离开驾驶或车辆数据中断时，反馈会停止。
- “连接与工具”的“查看详细运行信息”提供车轮数据、效果来源、音频格式及性能信息，供排查问题时使用。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 没有识别到手柄 | 检查数据线、USB 接口；退出其他占用手柄的软件，再重新连接。 |
| 找不到手柄音频设备 | 在 Windows 声音设置中启用手柄播放设备，重插 USB，然后刷新音频设备。 |
| 提示声道或格式不支持 | 将手柄播放设备配置为四声道；检查采样格式。仅有两声道时无法使用本程序的 USB 音圈输出。 |
| 有输出电平，握把没有震动 | 检查手柄播放设备和应用音量是否静音；关闭空间音效、音效增强及其他手柄震动软件。 |
| 检查有震动，驾驶时没有 | 确认已进入驾驶、游戏未暂停，路面/路肩已启用且强度大于零；查看车辆数据连接状态。 |
| 普通粗糙路面出现路肩震动 | 关闭“根据连续颠簸补充路肩识别”，再检查实际路肩上的反馈。 |
| 反馈被其他震动盖住 | 先降低引擎和打滑强度，再调整路面与路肩。 |
| R2 平时没有阻力 | 默认只在 TC 介入时施加阻力。如需基础阻力，关闭 TC 专用选项并启用 R2 基础阻力。 |
| 界面提示日志达到上限 | 点击“停止记录驾驶数据”，需要时再开始记录。既有文件保留，可从日志文件夹查看。 |

## 车型参数与数据记录

“导出车型模板”需要已经读取到当前车辆。模板可填写车辆物理参数；只有经过验证、标记 `Verified=true`，且游戏版本、车型、类别完全匹配时才会自动应用。修改验证标记前请确认参数依据。各效果强度仍通过主界面设置。

点击“开始记录驾驶数据”保存诊断信息，停止后从日志文件夹取得记录。主动记录采样最高为遥测 50 次/秒、输出 10 次/秒；自动诊断状态最高 2 次/秒。同一连续错误最多每 10 秒记录一次。单文件上限分别为 128 MiB 和 16 MiB，常规记录不保存完整共享内存快照。

日志可能含车型、赛道、设备名称与设备标识。提交 GitHub Issue 时，描述 Windows 版本、连接方式、车辆/赛道、具体现象和手柄检查结果，并在附件上传前检查日志内容。
