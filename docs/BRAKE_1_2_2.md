# v1.2.2：无 ABS 刹车反馈

## 三种触感

- **基础阻力**：无 ABS 分支使用 [0,1,1,2,2,3,3,4,4,5] × 基础力增益，四舍五入到手柄 0–8 级。前段更轻，低强度不再被向上取整成全行程至少 1 级。很低的强度可能低于硬件最小等级，此时输出关闭。
- **临界滑移提示**：逐轮纵向制动滑移达到预警阈值时，在估计的当前扳机位置附近增阻。保留有界滑移增长趋势预测。检测门槛与强度分开：强度调低不会推迟首次提示；强度为 0 或关闭功能则完全关闭。
- **明显抱死提示**：滑移进入抱死区间，改用手柄原生 0x26、24 Hz 振动模式，在全行程产生脉冲。由手柄生成频率，不依赖主机更新时的一档力变化。退出抱死后恢复临界增阻或基础力。该模式期间不会叠加静态阻力墙。

GT3 自动识别与旧版 LT 分支保持不变。手动 ABS 介入阻力墙保持不变。R2、路面与音圈算法未修改。

## 纵向滑移的信号链

无 ABS 分支统一使用 LMU 纵向接触区速度和轮胎局部地面速度：

`brakeSlip = clamp(LongitudinalPatchMps / GroundLongitudinalMps, 0, 1)`

这一有符号比例在制动时为正，驱动打滑时为负；全抱死接近 1。仅对接地且局部纵向速度至少 5 m/s 的车轮使用，并逐轮校验：

1. 比值必须在 −2 到 1.05 范围内，数值必须有限。
2. 车轮转动时 `(ground − patch) / omega` 必须落在 0.15–0.60 m 的合理滚动半径范围内。这是同一物理帧的量纲一致性检查，不需要先学习轮径。
3. 车轮角速度绝对值 ≤0.5 rad/s 时，仅接受 patch 与 ground 相差不超过 5% 的锁止证据。

无有效信号的车轮不参与风险判断，状态区显示有效数量。没有有效车轮时立即清除滑移事件。不会把缺失接触区速度转换成假定滑移；因此需要具体车型正常输出这一字段。共享轮径学习仍供其他既有算法使用，无 ABS L2 不再被它阻塞。

保留 6% 预警、16% 临界、25% 抱死增强终点；40 ms 有界趋势前视，8 ms 攻击、40 ms 释放。预警阈值不是已测得的轮胎最佳滑移率；前视时间也不是保证的手指感知提前量。临界信号仍依赖已经出现的早期滑移。

## 参考墙与标定

未标定参考墙不再持续增阻。只在同工况至少三次独立制动取得有效滑移起点、置信度达到 0.3 后，才允许输出至多 2 级的轻参考墙。采样资格改为有效接触区滑移，不再要求全局轮径学习完成。工况隔离、载荷及横向状态修正沿用 v1.2.1。

未标定的估计位置可以在诊断中查看，但不会被伪装成已知制动极限。首次驾驶主要依靠轻基础力和实时滑移提示。

## 调节与验证

使用原有基础力与临界提示强度即可，无需重置个人配置。先保持自动模式、打开“临界制动预警”；若基础力仍偏重，降低其强度。关闭该功能或强度设为 0 会同时关闭临界增阻、参考墙和抱死脉冲。

行程映射仍支持游戏起始死区、满刹行程和曲线指数。程序不读取物理 L2 行程，临界增阻位置会受映射误差影响；抱死脉冲使用全行程，避免局部位置偏差使提示失效。

诊断日志新增 Slip、Risk、ValidSlipWheels；界面和输出日志明确区分 BrakeLimit、LockPulse、BrakeReference、BrakeBase。回归测试覆盖低强度起刹、未标定参考墙关闭、无轮径学习的早期滑移、启动即抱死、单轮持续抱死、增益与触发门槛分离、松刹/低速/离地/断流释放及最终 USB HID 字节。公开仓库仅包含人工构造的新测试数据，不包含本次用户上传的驾驶日志。

软件回放不等于真实手柄触感验证；实际强度、首次可感知时间和临界点仍需复测。
