# LMU DualSense Haptics v1.3-preview

强化无 ABS 车辆的临界制动提示，修正近锁止信号可能被拒绝和有效遥测包之间提示衰减的问题。

- 临界提示改为全行程 12 Hz 硬件脉冲；明显抱死为优先级更高的 24 Hz 脉冲，首个有效样本即可触发。
- 增加逐轮滞回与默认 160 ms 提示尾部，减少一闪而过；松刹、低速、离地、信号失效、换车或暂停仍立即取消。
- 在速度域校验接触区滑移，避免近锁止时除以很小的轮速。无 ABS 不再在有效物理帧之间指数衰减。
- 增强中低强度设置下的提示幅度，轻基础力保持原样。GT3 旧版 LT、反复车型切换、手动 ABS、R2/音圈分支保持。
- 补充 F1 25 官方遥测与现成 DualSense 项目的设计参考，以及提示状态诊断。

下载 `LMUDualSenseHaptics-win-x64-v1.3-preview.zip`，完整解压运行。沿用个人配置，确认“临界制动预警”开启且强度大于 0；新脉冲较强，可按需降低该项强度。

验证：207 项回归、85 项静态检查及 10 组合成回放；发布流程在最终提交上执行 Windows 构建与检查。新增测试包括 250–360 km/h 瞬间满刹锁轮、多种遥测频率、保持/取消条件和最终 HID 字节。

这是预览调校，尚未进行实体手柄和慕尚赛道验证；并非 F1 25 内部算法的复刻，也不保证第一次突然锁轮前必有预警。详见 [算法与验证边界](https://github.com/zonda-xu/LMUDualSenseHaptics/blob/v1.3-preview/docs/BRAKE_1_3_PREVIEW.md)。
