# LMU DualSense Haptics v1.3.5-preview

本版优先恢复正常制动脚感，将持续控制信息与严重事件分开。

- 自动 GT3 使用 v1.0.1 刹车逻辑，新增该标签源码的全链路对照验证。
- 无 ABS 基础阻力成为独立可调曲线，支持起段、末段和曲线指数；非零设置至少输出 1 级。
- 临界滑移改为渐进增阻；严重抱死输出约 120 ms 的 24 Hz 短脉冲，然后恢复持续阻力。同一次抱死不反复报警。
- 脉冲两端调整幅度，减少编码突变；保留松刹、失效、低速、暂停和换车取消规则。
- 增加参考墙的有效样本、实际输出及离线覆盖率/位置偏差评估。没有真值时不把“未确认提示”当作误提示率；本版不增加预测复杂度或混用工况。

下载 `LMUDualSenseHaptics-win-x64-v1.3.5-preview.zip`，完整解压运行。保留个人配置；基础阻力在很低的非零强度下也会有最低 1 级，若要完全关闭请设为 0 或关闭该项。新曲线调节位于刹车设置中。

验证：217 项 C# 回归、87 项静态检查、10 组合成回放及 5 项参考墙统计测试。发布流程在最终提交上完成 Windows 构建和检查后上传 ZIP 与 SHA-256。

实际 DualSense 模式切换的力感连续性和赛道收益尚待实测。机制、Codemasters 原始资料及评估方法见 [v1.3.5-preview 说明](https://github.com/zonda-xu/LMUDualSenseHaptics/blob/v1.3.5-preview/docs/BRAKE_1_3_5_PREVIEW.md)。
