# LMU DualSense Haptics v1.3.9-preview

按要求从 **v1.3-preview** 基线开发，保留该版刹车、油门和震动算法；不包含 v1.3.5-preview 的刹车逻辑调整。

- **车辆专属扳机配置**：按车型名称＋类别自动应用 L2 / R2 设置，可连续换车并恢复先前配置；未配置车辆使用通用设置。
- **独立编辑和保存**：创建、编辑、删除车辆配置；面板可跟随当前车，也可编辑已保存的其他车型。输出始终跟随游戏当前车辆。包含模式、强度、开关、行程映射及独立的 R2 升挡设置，握把与音频保持通用。
- **Material 风格**：新增配置卡片、状态、按钮、开关和下拉框延续浅色/深色语义配色，统一现有车辆、刹车模式和音频选择器。
- **清爽解压目录**：根目录文件只有 `LMUDualSenseHaptics.exe`，全部运行组件在 `bin/`，文档和许可证在 `docs/`。自包含运行，支持中文和空格路径。

下载 **LMUDualSenseHaptics-win-x64-v1.3.9-preview.zip**，完整解压到新文件夹后双击根目录 EXE。请保留 `bin` 与 `docs`，不要覆盖到旧版平铺目录，以免旧 DLL 留在外层。配置和日志继续保存在 LocalAppData。

识别到车型后，在“扳机反馈 → 车辆扳机配置”点击“为此车创建配置”，调整后点击“保存配置”。详细步骤见 [车辆配置说明](https://github.com/zonda-xu/LMUDualSenseHaptics/blob/v1.3.9-preview/docs/VEHICLE_TRIGGER_PROFILES.md)。

验证：215 项 C# 回归测试、91 项静态检查、10 组合成遥测回放；Windows 发布流程另外验证原生启动器、解压目录、中文/空格路径、不同工作目录、WPF 窗口启动、Material 下拉框和正常退出。实体手柄与游戏内驾驶手感仍需实测。
