# LMU DualSense Haptics v1.2.2

修正无 ABS 车辆“起刹偏重、临界和抱死提示不明显”的反馈链路。

- 减轻基础曲线，移除低强度被向上取整为全行程最低阻力的行为。
- 未标定时不输出持续参考墙；取得足够独立制动样本后才输出轻参考。
- 使用经逐轮校验的纵向接触区滑移，无需等待全局轮径学习。临界检测门槛与强度分开。
- 明显抱死改为原生 24 Hz 全行程 L2 脉冲，与临界静态增阻形成明确区别。
- 增加滑移有效性、风险与脉冲来源诊断，以及对应回归测试。

GT3 旧版 LT、自动反复换车、手动 ABS 阻力墙及 R2/音圈算法保持原样。

下载 `LMUDualSenseHaptics-win-x64-v1.2.2.zip`，完整解压运行。无需重置个人配置；请确认“临界制动预警”已开启且强度大于 0。

需要车辆提供有效纵向接触区速度。软件验证不能保证真实手柄的感知提前量或最佳制动点。详见 [v1.2.2 刹车说明](https://github.com/zonda-xu/LMUDualSenseHaptics/blob/v1.2.2/docs/BRAKE_1_2_2.md)。

验证：193 项回归、85 项静态检查及 10 组合成回放；发布流程在最终提交上完成 Windows 构建和检查后上传 ZIP 与 SHA-256。
