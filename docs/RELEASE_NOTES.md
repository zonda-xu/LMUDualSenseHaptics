# LMU DualSense Haptics v1.2-preview

本版本是预览版，稳定版仍为 v1.0.1。

- 新增自动 / 有 ABS / 无 ABS（含 ABS 关闭）刹车模式。
- 有 ABS：根据实际介入建立本次制动的 L2 阻力墙，松刹车释放。
- 无 ABS：结合逐轮滑移与轮速相对地速的下降趋势，提前增加 L2 阻力；新增每轮刹车压力及接触面滑动比例辅助信号。
- 分别监测前后轮风险，避免单个后轮抱死被平均稀释。
- 抱死时保留基础刹车阻力，增加浅幅阻力变化，替换原先 8 Hz 低幅振动替换阻力的方式。
- 新增诊断、算法回归与遥测字段测试；R2 与路面/路肩音圈算法保持原样。

下载 `LMUDualSenseHaptics-win-x64-v1.2-preview.zip`，完整解压后运行 EXE。自动识别与车辆实际 ABS 设置不符时，在刹车设置中选择对应模式。

**体验边界：**默认预警区间 6%–16% 是待实车验证的工程阈值，不代表已测得的轮胎最佳滑移率。阻力墙位置按线性刹车输入估算，仅为触觉提示，不限制刹车输入。首帧前已存在的滑移、游戏遥测延迟及实际手柄响应无法由合成测试证明。完整说明见 `docs/BRAKE_PREVIEW.md`。
