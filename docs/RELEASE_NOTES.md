# LMU DualSense Haptics v1.2.1

- 修复自动切换：逐帧识别 GT3 / LMGT3，支持 GT3 → Hyper → GT3 反复切换，无需重启。其他车型使用新预测逻辑；手动模式可随时返回自动。
- GT3 恢复旧版 LT 基础曲线、ABS 优先级、15 Hz ABS 与 8 Hz 抱死提示。仓库未找到 v1.1 标签，实际采用可核对的 v1.0.1 旧逻辑基线。
- 其他车型增强起刹基础阻力，零滑移时就预设临界阻力参考位置，按横向负荷、经有效性检查的轮胎减载、刹车输入及压力变化提前调整。
- 只从独立制动的小滑移起点学习参考，不把一次未抱死的输入当作极限。样本按车速、横向状态、分配/迁移、回收及轮胎条件隔离。
- 新增工况遥测、置信度、物理帧间隔及输出诊断；新增游戏刹车死区/行程/曲线映射设置。

下载 `LMUDualSenseHaptics-win-x64-v1.2.1.zip`，完整解压后运行 EXE。选择“自动切换：GT3 旧版 / 其他车型预测”启用反复识别。手动模式不会自动覆盖。

初始上限是未标定参考，不是“剩余抓地力”或最佳制动点。没有真实手柄与赛道试车结果，不能承诺提前多少毫秒。接触区速度与轮胎力仅录制用于后续核验。详见 [算法与验证说明](https://github.com/zonda-xu/LMUDualSenseHaptics/blob/v1.2.1/docs/BRAKE_1_2_1.md)。
