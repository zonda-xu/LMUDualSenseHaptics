# v1.5：车辆扳机配置与分享

本版基于 `v1.3.9-preview`，新增单车配置的导入与导出。无 ABS 提示的强度映射由平方根改为线性，以减轻默认/中档的力度；提示阈值、时序和自动车型识别保持原有逻辑。

## 为当前车辆创建配置

1. 进入 LMU，等待顶部显示车辆名称和类别。
2. 打开“扳机反馈”，保持“编辑面板跟随当前车辆”勾选。
3. 点击“为此车创建配置”，复制通用扳机设置。
4. 单独调整 L2 / R2 的模式、各效果开关和强度，以及刹车轴死区、满刹行程、曲线指数。
5. 点击“保存配置”，保存全部车辆配置。修改立即生效，未保存的修改不会跨进程保留。

换车后，输出会按新车辆自动选择配置。A → B → 未配置车辆 → A 可以反复切换。取消“编辑面板跟随当前车辆”只固定编辑对象，不会停止输出自动识别。下拉列表可编辑所有已保存的车型，当前未配置车型也会出现在列表中。

“当前输出配置”显示游戏车辆实际选用的配置，下面的列表是正在编辑的配置，两者可以不同。效果读数始终表示当前输出，不是其他车型的预览。尚未创建专属配置的车辆使用通用设置，编辑区暂不可操作，点击创建后即可调整；也可从列表选择通用设置统一调整未配置车辆。

删除某车配置后，该车恢复通用设置。删除后仍需保存。恢复全部默认值会删除所有车辆扳机配置，保留既有的物理参数预设。

## 分享与导入

- 在车辆列表中选择已创建的单车配置，点击“分享此车配置”，将导出的 JSON 文件发送给其他用户。导出包含编辑面板中的当前参数，即使尚未点击“保存配置”也可分享。
- 点击“导入车辆配置”选择分享文件。程序按文件中的车型名称和类别保存，并在识别到该车时自动使用。导入后编辑面板显示导入的车，实际输出仍跟随游戏当前车辆。
- 本地已有同车型配置时，替换前会确认；取消不会修改配置。导入成功会保存配置，重启后仍然有效。格式、版本、必要字段和参数范围不合法的文件会被拒绝。
- 分享文件只包含车型身份、L2 / R2 设置和制动参数，不包含其他车辆配置、音频设备、个人路径、日志或握把设置。通用设置需先复制为某车专属配置再分享。
- 此功能与“导入车型预设”分开，后者处理物理参数。两个文件格式不能互换。

## 识别与设置范围

- 身份使用遥测 `VehicleModel + VehicleClass`，忽略首尾空格和大小写；不以会话车号、车位或游戏版本为键。游戏提供相同车型名称和类别的车辆共用一份配置，不细分同车型的单个参赛车手。
- 未读到车型或类别时，不创建身份，不沿用上一辆车的专属设置。暂停、断线、过期遥测继续关闭反馈。
- 范围：刹车/油门模式、L2 基础/ABS/临界制动、R2 基础/TC/空转/升挡/转速、制动行程映射和对应制动参数。R2 升挡强度与握把升挡强度分别调整。
- 路面、握把震动、音频设备、主题和 HID 设置保持全局。车辆扳机配置与“导入车型预设”不同，后者仍用于已验证的物理参数。
- 有专属配置时，该配置中的 `BrakeResponse` 优先于已导入物理预设中的同名部分；其他物理参数保持预设值。

配置保存于 `%LOCALAPPDATA%\LMUDualSenseHaptics\profile.json`，新增 `TriggerDefaults` 和 `VehicleTriggers`。旧配置没有这些成员时沿用原有通用参数，不需要迁移文件。原有物理预设、日志和存储位置不变。沿用以前个人配置时，已保存的数值仍会保留；如需本版初始值，可在界面恢复默认后保存。

## 发行目录

| 路径 | 内容 |
| --- | --- |
| `LMUDualSenseHaptics.exe` | 唯一的根目录文件，双击启动；带应用图标的原生 x64 启动器 |
| `bin/` | 自包含 WPF 应用、.NET、DLL 和其他运行组件 |
| `docs/` | 说明、许可证和第三方声明 |

完整解压到新目录。不要单独移动 EXE，也不要将新包覆盖到旧版平铺目录，否则旧版 DLL 仍留在外层。启动器按自身路径查找 `bin`，支持中文、空格路径及快捷方式的不同起始目录；原始命令行参数传给应用，关闭后返回应用退出码。不需要管理员权限。

## 验证边界

新增回归覆盖连续换车、身份归一化、未知车辆、配置读写、删除/断线恢复、通用与专属配置隔离，以及握把输出不受扳机增益影响。Windows 打包检查会真正打开解压后 WPF 窗口并展开下拉框。合成遥测与 UI 自动化不能代替 LMU 实车、实体 DualSense 的驾驶手感验证。
