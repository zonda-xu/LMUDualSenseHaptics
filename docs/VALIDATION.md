# v1.0.1 验证说明

本版基于 v1.0.0，仅增加图标资源并更新版本与发布说明。

## 修改范围

- Assets/AppIcon.png：原始提供图片，逐字节保留。
- Assets/AppIcon.ico：多尺寸 Windows 图标（16、24、32、48、64、128、256 像素）。
- LMUDualSenseHaptics.csproj：版本 1.0.1、EXE 图标及 WPF 图标资源嵌入。
- MainWindow.xaml：版本标识和窗口图标。
- README、更新日志与发布说明：同步 v1.0.1。

除项目文件及窗口 XAML 外，生产源码与 v1.0.0 逐字节一致；反馈算法、配置、日志逻辑和默认参数保持一致。

## 本次验证（2026-10-12）

- .NET SDK 8.0.415，Release win-x64 自包含发布成功，编译无警告或错误。
- 88 项现有静态检查通过，包括 XAML、资源引用和事件绑定。
- ICO 格式及全部 7 个尺寸检查通过。
- 编译出的 EXE 包含全部 7 个图标图像；WPF 程序集包含完整 ICO 资源。
- EXE 产品版本为 1.0.1。
- 源码 ZIP 完整性与图标文件包含检查通过。

本次是图标与版本更新，未重新运行反馈算法测试或实体手柄测试。v1.0.0 的 143 项回归及 10 组回放结果为前版验证记录。本环境没有运行 Windows 桌面；实际任务栏和资源管理器显示需在 Windows 上确认。

运行 build.cmd 可重新构建、运行 C# 回归并生成 Windows 应用。图标在构建时嵌入，无需额外转换工具或外部图标文件。
