# v1.3-preview：持续临界提示与高速锁轮响应

本版针对无 ABS 车辆的短促、偏弱提示，以及高速瞬间重刹时可能被信号校验或输出链路压掉的提示。它没有增加一个“满刹就是抱死”的规则，也不声称已测得轮胎最佳制动点。

## 感受上的变化

| 状态 | L2 输出 |
| --- | --- |
| 正常行驶、正常制动 | 沿用 v1.2.2 的轻基础曲线；未标定时不加持续参考墙 |
| 早期制动滑移或有界趋势达到预警门槛 | 全行程 12 Hz 硬件脉冲，代替手指位置附近的静态增阻 |
| 实测滑移达到抱死门槛 | 当前有效物理帧立即输出全行程 24 Hz 脉冲，优先于临界提示和参考墙 |
| 信号短暂回落 | 保持短提示尾部，避免只闪一下；逐轮进入/退出门槛分开 |
| 松刹、低速、倒挡、失去接触或有效信号、暂停/断流 | 取消对应提示；不强制播放完保持时间 |

脉冲由 DualSense 固件产生，覆盖 0–9 区，不依赖游戏刹车输入与物理 L2 行程的精确对应。脉冲期间不会同时叠加静态阻力墙。真实手柄在满行程下的可感知强度仍需实测。

## 信号与时序

仍用逐轮 `patch / ground` 计算有符号制动滑移，保持接地、至少 5 m/s 的轮胎局部纵向速度及有效数值校验。驱动空转、横向滑动和单纯大刹车输入不构成锁止证据。

以前通过 `(ground - patch) / omega` 校验半径，接近锁止时分子和分母都很小，可能将一致的近锁止信号判为无效。本版直接在速度域检查：

```text
min(0.15 × omega, 0.60 × omega) - 0.5
    <= ground - patch <=
max(0.15 × omega, 0.60 × omega) + 0.5
```

单位为 m/s；0.15–0.60 m 是宽范围一致性约束，0.5 m/s 是有界残差容忍量，均不是车型标定结果。无需等全局轮径学习。静止轮的缺失/零接触区速度仍会被拒绝；没有把未提供的遥测假定为已锁轮。此处修复的是可构造复现的数值问题，不能单凭它认定所有高速漏报的原因。

预警默认仍为 6%，40 ms 有界滑移趋势前视。进入预警后，预测滑移降至 4.2% 以下才开始结束提示尾部；实测滑移达到 25% 立即进入 24 Hz 阶段，回落至 16% 以下才开始退出该阶段。每轮独立记录最后一次支持信号的源时间，默认尾部 `CueHoldSeconds = 0.160`，配置允许 0.08–0.30 s。重复包不推进检测、不延长截止时间；某轮失去接触/有效性立即取消该轮保持。

无 ABS 的硬件效果在有效物理包之间保持，不再每次输出都按 40 ms 指数衰减。统一遥测看门狗仍计入 `SourceAgeSec`，默认 250 ms 超时后全关。保持提示不能越过暂停、离开驾驶、断连、换车、模式变化或时间重置。

## 力度

无 ABS 脉冲采用 `sqrt(临界制动预警增益)` 映射到 1–8 级固件幅度。临界阶段强度系数为 `0.55 + 0.35 × Risk`，抱死阶段为 `0.85 + 0.15 × LockSeverity`。这让中低滑块设置下的首次提示仍可形成数个等级，抱死阶段更突出；增益为 0 或关闭功能仍完全关闭。

例如 35% 增益下，临界脉冲约为 3–5 级，抱死脉冲为 5 级。等级是软件命令，不是牛顿力，也不保证不同手柄体感相同。无需重置个人配置，基础力保持原值。若新脉冲过强，降低“临界制动预警”的强度。

## 参考方案与边界

查阅 [F1 25 官方 UDP v3 文档](https://forums.ea.com/t5/s/tghpe58374/attachments/tghpe58374/f1-games-game-info-hub-en/61/4/Data%20Output%20from%20F1%2025%20v3.pdf)：Motion Ex 提供逐轮速度、滑移率、滑移角和横纵垂向力。文档并未给出 F1 25 内部 DualSense 控制算法；本项目没有接入 F1 UDP，也未声称复刻该游戏触感。

已有 [HorizonHaptics](https://github.com/haritha99ch/HorizonHaptics) 用滑移门槛控制 L2 振动；[Forza-Horizon-DualSense-Python](https://github.com/HamzaYslmn/Forza-Horizon-DualSense-Python/blob/236682fa998c90a3d11f9ca32f6adf72594fbeef/src/modules/forzahorizon/effects.py) 将滑移脉冲放在静态刹车阻力之前，并对阻力墙采用进入/退出滞回。后者采用自定义 source-available 许可，并非通用开源许可；本版仅参考公开行为与概念，没有移植其代码或参数。

这里的 12/24 Hz、160 ms 和强度曲线是本项目的预览调校，不是上述游戏或项目的实测最佳值。已学习参考墙沿用原有工况隔离和置信度门槛；未标定时依然依赖已经发生的早期滑移，无法保证在第一次突然锁轮之前给出可利用的预告。

## 验证与复测

合成回归覆盖 250/300/360 km/h 下全行程瞬间锁轮、近零轮速残差、20/30/50/60/100/250 Hz 源帧、最终 HID 字节、短事件保持、阈值抖动、逐轮失效、松刹和超时、反复 GT3/Hyper 切换。GT3 自动旧版 LT、手动 ABS、R2 和音圈算法继续使用原分支。

日志的 `Brake` 增加 `WarningActive` 与 `LockActive`；输出来源仍为 `BrakeLimit` / `LockPulse`，可结合实际效果模式和频率检查是否正确发出。实机复测可依次比较渐进直线刹车、拖刹、慕尚高速一次满刹，并记录从下刹前到松刹后的驾驶数据。若车辆滑动而有效滑移轮数为 0，必须先核实该车的遥测输出；本版不会用猜测的锁止信号遮盖它。

软件回放验证检测与命令，不等于真实 DualSense 感知验证。公开新增测试全部为合成数据，不含用户驾驶日志。
